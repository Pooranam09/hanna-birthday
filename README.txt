# Hanna's Dreamy Birthday Website 🎀

A responsive birthday surprise website made with plain HTML, CSS and JavaScript.

## Run it on your laptop
1. Extract `hanna_birthday_website.zip`.
2. Open the `hanna_birthday_website` folder.
3. Double-click `index.html` to open it in your browser.
4. For the best experience, use Chrome or Edge.

No installation or build tools are required. The Google Fonts link needs an internet connection; the website still works without it.

## Add Hanna's photos
1. Open the `photos` folder.
2. Add three photos and name them exactly:
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
3. Refresh the page. The gallery uses local photos, so they travel with the project folder.

Use photos you have permission to share. If your photos are PNG files, either convert them to JPG or change the matching filenames in `index.html`.

## Birthday date and message
The welcome screen now highlights October 23. The gift reveal and birthday letter have been customized with a cute, wholesome, sweet-and-heartfelt tone for Hanna.

## Personalize the birthday letter
Open `index.html` in Notepad or VS Code. Find the section beginning:
`<section class="section letter-section" id="letter">`
Edit the paragraphs inside that section. Save, then refresh your browser.

You can also change the birthday wish inside the `surprise-message` section.

## Share it with Hanna
The folder works locally on your laptop. To share a public link, publish the folder using a static hosting service such as GitHub Pages or Netlify. Upload the whole project folder, including `photos`, `style.css`, and `script.js`. Test the published link on your phone before sending it.

## Project files
- `index.html` — page content
- `style.css` — colors, layout, animations and responsive design
- `script.js` — gift interaction, floating hearts, gallery preview and wish button
- `photos/` — put your own photos here
